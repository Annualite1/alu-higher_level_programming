# python-test_driven_development

This project covers Test-Driven Development (TDD) in Python: writing doctests, interactive tests, and unittests, and using them to guide the implementation of functions.

## Learning Objectives

- What's Python's built-in documentation and how to use it
- What is Test-Driven Development
- How to create tests using doctests and the `unittest` module
- How to explain what duck typing is
- How to raise exceptions with `TypeError` and `ValueError`
- How to handle different types of exceptions
- What are the basics of error handling
- How to find the right module to import for a task
