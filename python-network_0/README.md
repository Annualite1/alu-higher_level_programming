# python-network_0

This project covers the basics of HTTP and networking using `curl` from the command line: sending GET, POST, DELETE, and OPTIONS requests, and working with headers, response bodies, and status codes.

## Learning Objectives

- What is a Local network
- Basic notions of the OSI Model
- What is a MAC/IP address
- What is `localhost`/127.0.0.1
- What is a port, and what does it mean to "listen on a port"
- How to send data over the internet using HTTP
- How to use `curl` to send GET, POST, DELETE, and other HTTP requests
- How to display and parse HTTP response bodies, headers, and status codes

## Files

| File | Description |
| --- | --- |
| `0-body_size.sh` | Displays the size (in bytes) of the response body |
| `1-body.sh` | Displays the body of a response if status code is 200 |
| `2-delete.sh` | Sends a DELETE request and displays the body |
| `3-methods.sh` | Displays all HTTP methods accepted by the server |
| `4-header.sh` | Sends a GET request with a custom header and displays the body |
| `5-post_params.sh` | Sends a POST request with `email` and `subject` parameters |
