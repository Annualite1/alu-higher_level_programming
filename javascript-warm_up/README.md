# JavaScript - Warm up

Introductory JavaScript scripts (Node 14, semistandard style) covering variables,
data types, control flow, loops, functions, recursion, objects and modules.

## Requirements
- Ubuntu 20.04 LTS, node 14.x
- First line of every file: `#!/usr/bin/node`
- All files executable and semistandard compliant

## Files
| File | Description |
|------|-------------|
| 0-javascript_is_amazing.js | Prints "JavaScript is amazing" using a const |
| 1-multi_languages.js | Prints 3 lines about C, Python, JavaScript |
| 2-arguments.js | Message based on number of arguments |
| 3-value_argument.js | Prints the first argument |
| 4-concat.js | Prints "<arg1> is <arg2>" |
| 5-to_integer.js | Converts first argument to an integer |
| 6-multi_languages_loop.js | Like task 1 using an array and a loop |
| 7-multi_c.js | Prints "C is fun" x times |
| 8-square.js | Prints a square of X |
| 9-add.js | Adds two integers with add(a, b) |
| 10-factorial.js | Recursive factorial |
| 11-second_biggest.js | Second biggest integer in arguments |
| 12-object.js | Updates an object value from 12 to 89 |
| 13-add.js | Exports an add function (used by 13-main.js) |
