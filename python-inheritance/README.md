# python-inheritance

This project covers Object-Oriented Programming in Python, focusing on inheritance, class hierarchies, and object introspection.

## Learning Objectives

- What is a base class, and how to list all attributes and methods of a class or instance
- How to define a class that inherits from another class
- How to accurately determine if an object is an instance of a class
- How to accurately determine if an object is an instance of a class or if the object is an instance of a subclass
- How to accurately determine the inheritance tree of an object
- When can a class have multiple parent classes
- What is the default class every class inherits from
- How to override a parent class's method
- Understanding the purpose of inheritance
- Understanding affordances of Python's multiple inheritance

## Files

| File | Description |
| --- | --- |
| `0-lookup.py` | Returns the list of available attributes and methods of an object |
| `1-my_list.py` | `MyList` class that inherits from `list`, with `print_sorted` |
| `2-is_same_class.py` | Checks if an object is exactly an instance of a specified class |
| `3-is_kind_of_class.py` | Checks if an object is an instance of, or inherits from, a specified class |
| `4-inherits_from.py` | Checks if an object is an instance of a class that inherited from a specified class |
| `5-base_geometry.py` | Empty `BaseGeometry` class |
| `6-base_geometry.py` | `BaseGeometry` with an `area` method that raises an exception |
| `7-base_geometry.py` | `BaseGeometry` with `integer_validator` |
| `8-rectangle.py` | `Rectangle` class that inherits from `BaseGeometry` |
| `9-rectangle.py` | `Rectangle` class with `area()` and `__str__` |
| `10-square.py` | `Square` class that inherits from `Rectangle` |
| `11-square.py` | `Square` class with `__str__` |
