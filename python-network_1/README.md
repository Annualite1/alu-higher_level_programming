# python-network_1

This project covers the basics of networking in Python: making HTTP requests, handling headers and errors, working with the `urllib` and `requests` packages, and interacting with real APIs (including GitHub's).

## Learning Objectives

- What are HTTP protocol, requests and responses
- What is the `urllib` package and how to use it
- What is the `requests` package and how to use it
- How to make an HTTP GET request with `urllib` and `requests`
- How to make an HTTP POST request with `urllib` and `requests`
- How to read the body and headers of a response
- How to catch and handle `urllib.error.HTTPError`
- How to handle status codes >= 400 with `requests`
- How to use Basic Authentication with the GitHub API
